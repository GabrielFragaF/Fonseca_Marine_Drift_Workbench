# Lucide gradient icon pack

This pack maps the Marine Drift Workbench icon vocabulary to official Lucide
icons. `original/` contains untouched source SVGs and `branded/` contains the
same geometry with the Marine Drift navy-to-cyan-to-turquoise gradient.

The mapping and official icon pages are recorded in `manifest.csv`. The pack is
generated by `desktop_app/tools/build_lucide_icon_pack.ps1`.
